# راه‌اندازی سیستم لایسنس (بدون پیامک) روی Supabase

این پوشه شامل دیتابیس و دو Edge Function است که به شما اجازه می‌دهد بدون
هزینه‌ی سامانه پیامکی، لایسنس بفروشید: مشتری فقط **نام + شماره موبایل** را
وارد می‌کند (بدون تایید OTP)، بعد از پرداخت یک **کد ۵ رقمی** به او نمایش داده
می‌شود، و برای ورودهای بعدی، هم شماره موبایل و هم کد را وارد می‌کند.

## چرا امن است با اینکه پیامک نداریم؟
شماره موبایل اینجا فقط برای «شناسایی مشتری» است، نه احراز هویت. امنیت واقعی
از این‌جا می‌آید:
- کد ۵ رقمی فقط سمت **سرور** (نه مرورگر) با دیتابیس مقایسه می‌شود.
- بعد از ۵ تلاش ناموفق برای یک شماره، ورود آن شماره ۱۰ دقیقه قفل می‌شود
  (`license-login/index.ts`) — یعنی حمله‌ی brute-force عملاً غیرممکن است.
- توکنی که بعد از ورود موفق صادر می‌شود، با کلید خصوصی ECDSA امضا می‌شود که
  فقط سرور دارد؛ مرورگر فقط کلید عمومی (برای تایید) را دارد. پس هیچ‌کس با
  دیدن کد سایت نمی‌تواند برای خودش توکن جعلی بسازد.

## مراحل راه‌اندازی

1. **ساخت پروژه Supabase** (رایگان، بدون کارت بانکی): در supabase.com یک
   پروژه جدید بسازید و منتظر بمانید تا دیتابیس بالا بیاید.

2. **نصب Supabase CLI** و لاگین:
   ```bash
   npm install -g supabase
   supabase login
   supabase link --project-ref <project-ref-پروژه‌تان>
   ```

3. **اجرای migration** (ساخت جدول licenses):
   ```bash
   supabase db push
   ```

4. **تولید جفت‌کلید امضا** (اگر هنوز نساخته‌اید):
   ```bash
   node scripts/generate-keypair.mjs
   ```
   - مقدار `PUBLIC_JWK` را کپی کنید و در `src/lib/license.ts`، ثابت
     `PUBLIC_KEY_JWK` را با آن جایگزین کنید (الان یک نمونه‌ی تستی آنجاست).
   - مقدار `PRIVATE_JWK` را به‌عنوان Secret تنظیم کنید (هرگز در گیت commit
     نشود):
     ```bash
     supabase secrets set LICENSE_PRIVATE_JWK='...مقدار PRIVATE_JWK...'
     ```

5. **دیپلوی Edge Function ها**:
   ```bash
   supabase functions deploy create-license
   supabase functions deploy license-login
   ```

6. **تکمیل تایید پرداخت واقعی**: در `supabase/functions/create-license/index.ts`
   بخش `TODO` را با API درگاه پرداختی که انتخاب می‌کنید (مثلاً زرین‌پال) پر
   کنید — راهنمای مختصرش همان‌جا کامنت شده. (این قسمت طبق برنامه‌ی خودتان،
   بعداً که درگاه را مشخص کردید انجام می‌شود.)

7. **تنظیم فرانت‌اند**: فایل `.env.example` را کپی کنید به `.env` و
   `VITE_SUPABASE_FUNCTIONS_URL` و `VITE_SUPABASE_ANON_KEY` را از
   Project Settings → API در داشبورد Supabase پر کنید.

8. **تست**: با `npm run dev` بالا بیاورید، یک رکورد تستی paid=true در جدول
   licenses از داشبورد Supabase بسازید (شماره + کد دلخواه)، و از فرم «شماره
   موبایل + کد لایسنس» در سایت وارد شوید.

## نگهداری دوره‌ای
- می‌توانید از داشبورد Supabase → Table Editor، جدول `licenses` را ببینید:
  چه کسانی خرید کرده‌اند، کد هرکدام چیست، و چند بار تلاش ناموفق داشته‌اند.
- اگر مشتری کدش را گم کرد، از همان جدول می‌توانید دستی کدش را پیدا کرده و
  (چون پیامک نداریم) از طریق تماس/ایمیل به او بگویید.
