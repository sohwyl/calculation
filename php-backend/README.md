# راه‌اندازی سیستم خرید و لایسنس (روی هاست شخصی شما، بدون Supabase)

این پوشه یک بک‌اند سبک PHP + SQLite است — روی تقریباً هر هاست اشتراکی ایرانی
(cPanel با پشتیبانی PHP 8+) مستقیم کار می‌کند، بدون نیاز به نصب چیز اضافه‌ای.

**جریان کامل:** مشتری نام+شماره را وارد می‌کند → به زرین‌پال می‌رود → پرداخت
می‌کند (بانک خودش احراز هویت دومرحله‌ای انجام می‌دهد) → برمی‌گردد → سرور شما
تایید می‌کند → کد ۵ رقمی ساخته و هم روی صفحه نشان داده می‌شود هم (اختیاری)
پیامک می‌شود → مشتری همین الان و برای همیشه با «شماره + کد» وارد می‌شود.

## چرا امن است (خلاصه)
- کد فقط سمت سرور (نه مرورگر) چک می‌شود؛ بعد از ۵ تلاش اشتباه، آن شماره
  ۱۰ دقیقه قفل می‌شود → brute-force عملاً بی‌فایده است.
- توکن ورود با کلید خصوصی ECDSA (فقط روی هاست شما) امضا می‌شود؛ مرورگر فقط
  کلید عمومی دارد که فقط برای «تایید»ست، نه «ساختن» امضا.
- (سازگاری امضای PHP↔مرورگر با تست واقعی تایید شده است.)

## مراحل نصب روی هاست

1. **آپلود:** کل پوشه‌ی `php-backend/` را (با FTP یا File Manager هاست) در
   یک زیرپوشه از سایت‌تان آپلود کنید، مثلاً `https://your-domain.example/php-backend/`.
   مطمئن شوید PHP نسخه‌ی هاست حداقل 8.1 باشد و اکستنشن‌های `pdo_sqlite`،
   `openssl` و `curl` فعال باشند (در اکثر هاست‌های ایرانی از قبل فعال‌اند).

2. **دسترسی نوشتن:** به پوشه‌های `php-backend/data` و `php-backend/keys`
   دسترسی نوشتن (chmod 755 یا از پنل هاست) بدهید تا PHP بتواند دیتابیس و
   کلید را در آن‌ها بسازد.

3. **ساخت کلید امضا:**
   ```bash
   php scripts/generate-keypair.php
   ```
   این را یا مستقیم روی هاست (از طریق SSH اگر دارید) یا روی کامپیوتر خودتان
   (اگر PHP نصب دارید) اجرا کنید. اگر روی کامپیوتر خودتان اجرا کردید، فایل
   `php-backend/keys/private.pem` ساخته‌شده را با FTP در همان مسیر روی هاست
   آپلود کنید (private.pem هرگز نباید در گیت‌هاب باشد — از قبل gitignore شده).
   مقدار `PUBLIC_KEY_JWK` که چاپ می‌شود را در `src/lib/license.ts` جای‌گذاری
   کنید (یا برای من بفرستید تا جایگزین کنم) و سایت را دوباره بیلد کنید.

4. **تنظیمات:**
   ```bash
   cp php-backend/config.example.php php-backend/config.php
   ```
   و مقادیر زیر را با اطلاعات واقعی خودتان پر کنید:
   - `ZARINPAL_MERCHANT_ID` — از پنل zarinpal.com (بعد از ثبت‌نام و تایید)
   - `SITE_URL` و `API_URL` — آدرس واقعی سایت و پوشه‌ی php-backend
   - `PRICE_TOMAN` — قیمت فروش
   - اگر پیامک می‌خواهید: `SMS_ENABLED => true` + `KAVENEGAR_API_KEY` +
     `KAVENEGAR_SENDER` (از پنل kavenegar.com بعد از خرید خط اختصاصی)

5. **تنظیم فرانت‌اند:** فایل `.env.example` را کپی کنید به `.env`:
   ```
   VITE_API_BASE=https://your-domain.example/php-backend
   ```
   سپس `npm run build` بگیرید و `dist/index.html` را روی سایت جایگزین کنید.

6. **تست:** ابتدا `ZARINPAL_SANDBOX => true` بگذارید و با کارت تست زرین‌پال
   یک خرید آزمایشی انجام دهید. بعد از اطمینان، `false` کنید تا پرداخت واقعی
   شود.

## نگهداری دوره‌ای
- جدول `licenses` در فایل `php-backend/data/licenses.sqlite` است. برای دیدنش
  می‌توانید هر ابزار مدیریت SQLite (مثلاً DB Browser for SQLite) را دانلود
  کنید و فایل را با FTP دانلود/بررسی کنید.
- برای پشتیبان‌گیری، همین یک فایل SQLite را دوره‌ای دانلود و نگه دارید.
- اگر مشتری کدش را فراموش کرد (و پیامک هم فعال نبود)، از همین فایل می‌توانید
  دستی شماره‌اش را پیدا و کد را به او اطلاع دهید.
